# OpenCAD 2D 뷰어

브라우저에서 DXF·DWG 도면을 열어 보고 재는 무료 2D CAD 뷰어입니다.
설치할 것이 없고, 서버도 쓰지 않습니다. 연 파일은 사용자 컴퓨터 밖으로 나가지 않습니다.

**바로 쓰기: <https://gyutae-kim.github.io/2dcad-viewer/>**

CAD·CAM 분야는 파일을 만든 프로그램이 없으면 도면을 열어 보기도 어렵습니다.
OpenCAD는 이 벽을 낮추려는 프로젝트이고, 이 저장소는 그 첫 번째인 2D 도면 뷰어입니다.
SKP·STEP·NC 같은 형식도 차례로 더할 계획입니다.

## 할 수 있는 것

- **열기**: DXF R12~R2018(ASCII·이진), DWG R13~R2018. 파일을 끌어다 놓거나 고르면 됩니다.
- **보기**: 휠 확대·축소, 가운데 버튼 이동, 전체 보기. 모형 탭과 배치 탭(용지·뷰포트·뷰포트별 동결 도면층)
- **도면 요소**: 선·호·원·타원·폴리선(폭·볼록도)·스플라인, 문자·여러 줄 문자(서식·쌓기·열), 블록·속성,
  치수(치수 블록), 지시선·다중 지시선, 해치(무늬·단색·그라데이션), 가리기, 여러 줄, 표, 선종류(복합 선종류 문자 포함), 선가중치
- **확인·측정**: 객체 선택과 특성(길이·면적·반지름 등), 거리·각도·면적·반지름 측정, 좌표(ID), LIST,
  객체 스냅(끝점·중간점·중심·사분점·교차점·삽입점·노드·수직·근처점), 직교
- **도면층**: 켜기·끄기·동결·격리, 도면층별 객체 선택
- **치수 목록**: 모든 치수의 표시 문자와 실제 측정값을 나란히 보여 주고, 문자를 바꿔 적은 치수를 찾습니다.
- **문자 찾기**: 도면 안 문자를 찾아 그 위치로 이동
- **내보내기**: PNG(지금 화면), SVG, PDF(배치는 용지 크기 그대로)
- **한글**: CP949(ANSI_949) DXF·DWG, SHX 큰 글꼴 자리의 한글을 Noto Sans KR로 그립니다.

AutoCAD를 쓰던 사람이 따로 배우지 않도록 화면 배치, 명령 이름·별칭(`DI`, `MEA`, `LA`, `Z` 등),
단축키(F3·F8·Ctrl+1 등), 마우스 동작을 AutoCAD와 같게 맞췄습니다. 도움말은 F1입니다.

## 구조

```
src/
  core/      문서 모델, 색(ACI), 코드 페이지, 단위, 치수 변수
  io/dxf/    DXF 리더(ASCII·이진)
  io/dwg/    DWG 리더(R13~R2018, ODA 공개 명세로 새로 작성)
  geom/      변환 행렬, 곡선 나누기(볼록도·NURBS·맞춤점 보간)
  text/      단선 글꼴(SHX 대신), 윤곽 글꼴 조각 받기, TEXT·MTEXT 배치
  render/    장면 빌더(블록 펼치기·선종류·해치·치수·지시선), 표시 목록, WebGL2 렌더러
  worker/    파일 해석과 장면 만들기를 맡는 웹 워커
  app/       화면·명령·선택·스냅·팔레트·내보내기
```

파일 해석과 그리기 준비는 웹 워커에서 하고, 화면 스레드는 확대·이동과 선택만 맡습니다.
좌표는 공간 격자 묶음 기준 float32로 올려 큰 좌표(예: 500000, 300000)에서도 확대했을 때 떨리지 않습니다.
같은 모양의 글자는 한 번만 GPU에 올리고 글자마다 변환만 둡니다.

## 개발

```bash
npm install
npm run dev       # http://localhost:5173
npm test          # 비교용 도면이 없으면 해당 테스트는 건너뜁니다
npm run build     # dist/
```

DXF·DWG 리더 테스트는 로컬 도면을 ezdxf 결과와 비교합니다(`scripts/oracle/`, `CAD_FIXTURES`·`CAD_PYTHON` 환경 변수).
비교용 도면은 저장소에 넣지 않습니다.

`main` 브랜치에 올리면 GitHub Actions가 빌드해 `gh-pages` 브랜치로 배포합니다.
