# 작업 내역

OpenCAD 2D 뷰어를 만들어 온 과정을 단계별로 정리했습니다. 커밋 하나하나는 `git log`에, 남은 일은 [ROADMAP.md](ROADMAP.md)에 있습니다.
모든 기능은 브라우저 안에서만 동작하며, 연 파일은 사용자 컴퓨터 밖으로 나가지 않습니다.

## 2026-10-15 (7): 공개 도면으로 확인한 AutoCAD 형식

표본 폴더에 없는 기능의 형식을 GitHub 등에 공개된 AutoCAD 도면 파일(DWG·DXF)로 확인해 넣었습니다. 도면 파일만 읽었고, 그 저장소의 코드는 보지 않았으며, 내려받은 도면은 저장소에 두지 않았습니다. 이 단계의 커밋은 `40738df`부터입니다.

### 파라메트릭 구속과 연관 배열
- AutoCAD에서 만든 파라메트릭 구속을 읽어 구속 막대·매개변수 관리자에 보이고, 형상을 고치면 이 앱 해법기로 따라갑니다. 고친 값·식·삭제는 AutoCAD 원본 구속 망에 같은 형식으로 저장합니다.
  - 기하 구속 11종(일치·점-곡선·평행·직교·수평·수직·접선·동일선상·동심·동일·고정), 수평·수직·정렬 거리와 반지름·지름 치수 구속, 변수.
  - 공개 도면의 AutoCAD 구속 759개를 읽어 모두 지금 형상에서 만족되는 것을 확인했습니다.
- 새로 만든 연관 배열(직사각형·원형·선 경로)을 AutoCAD 연관 객체로 저장해 AutoCAD에서도 연관 배열로 보입니다.
- DWG 안의 AutoCAD 연관 객체(배열·구속)를 해독하고 씁니다. 공개 DWG·DXF 짝의 연관 객체 1011개를 비트 단위로 왕복해 확인했습니다.

### 동적 블록
- DWG 동적 블록 객체를 9종에서 30종으로 늘렸습니다. 이제 DWG로 연 뒤집기·XY·회전·조회·점·극좌표·정렬·기준점 정의를 편집하고, 다른 버전으로 저장해도 정의가 남습니다.
- 표본·예제·공개 짝 도면의 동적 블록 객체 1,954개 가운데 1,948개가 남는 비트 없이 풀립니다.

### 도면층 필터·CAD 표준
- 도면층 필터를 AutoCAD 형식으로 읽고 써서 AutoCAD에서 만든 필터가 보이고, 이 앱에서 만든 필터도 AutoCAD에 보입니다. 바꿀 수 없는 필터 식은 읽기 전용으로 보존합니다.
- CAD 표준 연결을 AutoCAD 형식으로 저장하고, 도면층 변환기(LAYTRANS)가 표준 파일(DWS)의 매핑을 불러오고 저장합니다.

### 주석 축척
- 명세만 보고 정했던 치수·MTEXT 레코드 배치를 실물과 맞췄습니다. 전에는 풀지 못하던 AutoCAD 치수·MTEXT 축척 레코드를 이제 읽고 그대로 저장합니다.
- 주석 해치는 AutoCAD처럼 뷰포트별 표현 레코드(HATCHVIEW)를 함께 저장합니다.

### 이 단계의 한계
- 실물이 없던 구속(각도·대칭 등)이 든 구속 그룹, 지운 배열 항목 플래그, 일부 동적 블록 값 목록은 원본 그대로 보존만 합니다.
- 이 앱이 새로 만든 구속은 아직 AutoCAD에서 보이지 않습니다.
- AutoCAD로 직접 열어 본 확인은 아직 없습니다.

## 2026-10-15 (6): 큰 도면 점진 빌드·문서 전송·묶음 무리

큰 도면을 열 때 기다리는 시간과 화면이 멈추는 시간을 줄였습니다. 이 단계의 커밋은 `a497c0a`부터입니다. 합성 100만 객체 DXF(203MB)로 쟀고, 저장 결과와 장면 그림은 고치기 전과 바이트까지 같습니다.

### 점진 빌드
- 장면을 다 만들기 전에 그림부터 보입니다. 워커가 장면을 만드는 동안 약 1초마다 그때까지의 그림을 조각으로 보내고, 화면은 진행 상자 뒤에 받는 대로 겹쳐 그립니다.
- 저장된 첫 화면(*Active 뷰)이 도면 일부만 보이면 그 안의 객체를 먼저 그려 보냅니다.
- 조각에는 첫 화면 밖의 묶음, 반 픽셀보다 작은 객체의 나머지 선분, 너무 작아 그리지 않을 글자를 넣지 않습니다(100만 객체 전체 보기에서 조각 264MB → 109MB).
- 브라우저에서 같은 파일을 열 때 파일을 다 읽은 뒤 첫 그림까지 약 10.8초 → 0.35초, 열기가 끝날 때까지 약 10.8초 → 5.3초가 걸렸습니다.

### 메인 문서 사본
- 문서를 장면 뒤에 보냅니다. 객체가 많은 블록(대개 모형 공간)의 객체는 5만 개씩 묶어 부호화합니다. 같은 속성 모양은 한 번만 적고, 수·문자열 표·바이트 배열은 형식 배열로 옮깁니다. 나머지는 예전처럼 구조화 복제로 보냅니다.
- 화면 스레드는 묶음을 받는 대로 풀어 붙이고 핸들 색인을 조금씩 채웁니다. 예전에는 문서를 한 번에 역직렬화하느라 약 7초(부하가 높을 때 30초 넘게) 멈췄지만, 이제 메시지 하나에 대개 40~120ms입니다. 화면 스레드의 문서 메모리도 약 770MB에서 590MB로 줄었습니다.
- 색인을 블록에서 다시 만들 수 없거나 부호화하지 못하는 값이 있으면 예전 방식으로 보냅니다.

### 묶음 그리기 호출
- 전체 보기처럼 멀리서 볼 때는 작은 묶음을 도면 크기 1/8 칸마다 합친 무리로 한 번에 그립니다. 크게 확대해 무리의 일부만 보이면 원래 묶음을 필요할 때 GPU에 올려 그리고, 오래 쓰지 않으면 내립니다.
- 100만 객체 전체 보기에서 선·채우기 그리기 호출이 10,811번에서 116번으로 줄었습니다(묶음 9,010개 → 무리 32개와 큰 묶음). 남은 병목은 GPU의 정점 처리입니다(한 장에 약 65ms).
- 편집으로 숨긴 객체는 무리 버퍼에도 반영합니다. 무리로 그린 화면과 묶음으로 그린 화면은 픽셀 몇 개만 다릅니다(깊이가 같은 곳의 그리는 순서 차이).

### 측정 도구
- `scripts/perf/measure.ts`: 문서 보내기를 예전 방식과 지금 방식(워커 쪽·화면 쪽 CPU, 메시지 하나에 멈추는 가장 긴 시간)으로 나눠 잽니다. `--partial`로 점진 빌드 조각 수와 바이트를, 전체 보기 그리기 호출 수를 함께 잽니다.
- `scripts/perf/gen-big.ts --zoom N`: 저장된 첫 화면을 도면 가운데 1/N 높이로 만듭니다.

## 2026-10-15 (5): 큰 도면·AutoLISP·도면층 필터

두 번째 묶음 네 갈래를 합쳤습니다. 이 단계의 커밋은 `e52c805`부터입니다.

### 큰 도면
- DXF를 파일 전체 문자열로 바꾸지 않고 바이트에서 바로 읽습니다. 예전에는 약 240만 객체(500MB대)를 넘는 ASCII DXF가 브라우저 문자열 한계로 열리지 않았습니다. 이제 합성 300만 객체 DXF·DWG를 읽고 그립니다.
- 100만 객체 기준으로 DXF 문서 메모리가 약 32%, 장면이 JS 힙에 남기는 메모리가 465MB에서 33MB로 줄었습니다. 장면 만들기는 약 45%, 워커에서 메인으로 보내는 시간은 약 60% 줄었습니다.
- 저장 결과와 장면 그림은 고치기 전과 바이트까지 같습니다. 도면을 열 때 "화면 그리는 중" 진행 막대가 실제로 움직입니다.

### AutoLISP
- 명령행에 `(…)`를 치면 평가하고, `!변수`로 값을 봅니다. 명령 프롬프트 안의 식은 그 값이 입력이 됩니다.
- `(defun c:이름 …)`은 새 명령이 되고, command·get*·getvar·setvar·entget·entmod·entmake·ssget(필터 포함) 등을 씁니다.
- 스크립트 안의 AutoLISP 식, APPLOAD와 .lsp 끌어 놓기.
- 파일 쓰기·외부 실행·ActiveX·DCL은 만들지 않았습니다.

### 도면층 필터
- 도면층 팔레트에 필터 트리, 특성 필터(13열 조건)·그룹 필터 대화상자, 필터 반전, 필터 메뉴(가시성·잠금·뷰포트 동결 등), FILTERS.
- AutoCAD의 필터 레코드 형식을 확인할 실물이 없어 이 앱 기록으로 저장합니다. AutoCAD에서 만든 필터는 보이지 않지만 원본은 그대로 남습니다.

### 다듬기
- 명령을 취소하자마자 다른 명령을 시작하면 새 명령의 입력 요청이 사라지던 경합을 고쳤습니다(스크립트·리본 단추에서 나던 문제).
- 기능들이 앱 메서드를 실행 중에 감싸던 것을 정식 확장 지점(`src/app/hooks.ts`)으로 옮겼습니다.
- 등각 설정이 도면(DXF VPORT 77·78, DWG VPORT)에 저장됩니다.
- DXF에서 읽은 AutoCAD 연관 배열을 DWG로 저장해도 배열로 남습니다.

## 2026-10-15 (4): 도면층 상태·Express Tools·스크립트

여섯 갈래로 나눠 개발하고 합쳤습니다. 이 단계의 커밋은 `d9d15fe`부터입니다. 전체 시험 2750개가 통과한 상태로 배포했습니다.

### 도면층
- 도면층 상태 관리자(LAYERSTATE, Shift+Ctrl+L)와 명령행(-LAYERSTATE, -LAYER의 상태(A))
  - AutoCAD와 같은 자리(LAYER 표 확장 사전의 `ACAD_LAYERSTATES`)에 같은 꼴로 DXF R2000 이상·DWG에 읽고 씁니다.
  - .las 파일과 다른 도면에서 가져오고, .las로 내보냅니다. 복원할 특성을 고를 수 있습니다.
  - 리본 도면층 패널에 상태 목록을 두어 고르면 바로 복원합니다.
- 도면층 이전(LAYERP·LAYERPMODE): 도면층 설정 변경을 한 단계씩 되돌립니다.
- ByLayer로 설정(SETBYLAYER·SETBYLAYERMODE): 블록 정의 안까지 바꿀 수 있습니다.

### Express Tools
- 리본에 Express Tools 탭을 새로 두었습니다.
- 문자: TCASE(서식 코드 보존), TCOUNT, TORIENT, TEXTFIT, TEXTMASK·TEXTUNMASK, TCIRCLE, TXTEXP
- 선택·조회: SSX, GETSEL, XLIST, XDLIST, NCOPY, GATTE
- 그리기·수정: BREAKLINE, MPEDIT, EXOFFSET, FLATTEN, CDORDER, MKLTYPE(.lin 내려받기), SHOWURLS, REDIR

### 스크립트
- SCRIPT·RSCRIPT·RESUME·DELAY: .scr 파일을 고르거나 끌어 놓으면 명령행에 차례로 넣습니다. 오류나 Esc에서 줄 번호와 함께 멈추고, 한 번 실행한 것이 명령 취소 한 번입니다.
- 스크립트에서 쓰는 명령행 버전 명령 14개: -INSERT, -ATTEDIT, -ARRAY, -HATCH, -BOUNDARY, -PURGE, -STYLE, -LINETYPE, -DIMSTYLE, -UNITS, -OVERKILL, -XREF, -IMAGE, -PLOT
- 페이지 설정 가져오기(PSETUPIN·-PSETUPIN)

### 연관 배열
- ARRAYRECT·ARRAYPOLAR·ARRAYPATH가 연관(AS) = 예(ARRAYASSOCIATIVITY 기본값)일 때 연관 배열 하나를 만듭니다.
- ARRAYEDIT(소스·대체·기준점·행·열·레벨·항목·방법·정렬·재설정)와 ARRAYCLOSE, 배열 그립, 특성 팔레트의 배열 항목, Ctrl+클릭으로 항목 지우기.
- 경로 곡선을 고치면 경로 배열이 따라갑니다.
- AutoCAD가 만든 DXF의 연관 배열(직사각형·원형·경로)을 읽어 고치고, 그 형식 그대로 다시 씁니다. 새로 만든 배열은 이 앱 기록으로 저장해 AutoCAD에서는 블록으로 보입니다.

### 화면·뷰포트
- 외부 참조 비교(XCOMPARE): 다시 불러온 외부 참조의 이전·지금 버전 차이를 참조 자리에 색과 구름형 리비전으로 보입니다. 외부 참조 창 메뉴에서도 시작합니다.
- 뷰포트 최대화(VPMAX·VPMIN): 배치 뷰포트를 화면 가득 키워 고칩니다. 최대화 중에는 Ctrl+R로 다음 뷰포트로 갑니다. 상태 막대에 단추를 두었습니다.
- 뷰포트 동기화(VPSYNC), 뷰포트 축척(VPSCALE)
- 채우기(FILL), 빠른 문자(QTEXT), 끌기 모드(DRAGMODE): 화면·PDF·SVG·플롯이 같은 규칙으로 그립니다.
- 등각투영 제도(ISODRAFT·ISOPLANE): 등각 격자·스냅·직교·추적과 등각원. F5·Ctrl+E로 평면을 바꾸고, 상태 막대 단추로 켭니다.

### 파일 형식
- 치수·해치·다중 지시선의 주석 축척 표현을 이 앱의 기록 대신 AutoCAD 축척 레코드로 DXF·DWG(R2000~R2018)에 저장합니다. 예전 기록이 든 파일도 계속 읽습니다.
- DWG의 문자·속성·블록 참조 축척 레코드를 읽고 씁니다. 표본 레코드 176개를 비트 단위로 왕복해 확인했습니다.

### 이 단계의 한계
- 치수·해치 축척 레코드는 표본에 실물이 없어 기능 명세의 배치를 따랐습니다. 이 앱이 쓴 파일을 AutoCAD로 열어 본 확인은 아직 없습니다.
- 도면층 필터는 표본에 자료가 없어 만들지 않았습니다. .las의 일부 코드 자리는 추측입니다.
- 스크립트는 AutoLISP을 실행하지 않고, 스크립트 안에서 파일 선택 창을 열 수 없어 이번 세션에서 연 파일만 이름으로 찾습니다.
- XCOMPARE는 모형 공간 최상위 참조만 비교하고, 이전 버전은 페이지 메모리에만 남습니다.
- 연관 배열은 표본에 실물이 없어 공개된 AutoCAD DXF 도면으로 형식을 확인했습니다. DWG 안의 AutoCAD 배열은 항목 배치로 짐작해 고칩니다.

## 2026-10-15 (3): 주석·구속·비교와 명령 보강

AutoCAD의 큰 기능 묶음을 여러 갈래로 나눠 개발하고 합쳤습니다. 이 단계의 커밋은 `cce9a5a`부터 `7778d8d`까지입니다.

### 치수·주석
- 연관 치수(DIMASSOC·DIMREASSOCIATE·DIMDISASSOCIATE·DIMREGEN): 형상을 고치면 치수가 따라갑니다.
- 검사 치수(DIMINSPECT·-DIMINSPECT): AutoCAD와 같은 `ACAD_DSTYLE_DIMINSPECT` 기록으로, 레이블·검사율 칸이 있는 원형·각도 프레임을 그립니다.
- 스마트 치수(DIM): 커서 아래 객체에 맞춰 선형·정렬·지름·반지름·각도 치수를 미리 보고 만듭니다. 기준선·계속·세로좌표·정렬·분산·도면층 옵션이 있습니다.
- 옛 지시선(LEADER): 스플라인·직선·화살표 형식과 여러 줄 문자·공차·복사·블록 주석.
- 주석 축척(CANNOSCALE·SCALELISTEDIT·OBJECTSCALE·ANNOALLVISIBLE·ANNOAUTOSCALE·ANNORESET·ANNOUPDATE)
  - 축척 리스트와 상태 막대 주석 항목, 뷰포트마다 다른 주석 축척으로 그린 모형 장면.
  - TEXT·MTEXT·블록 참조·속성은 AutoCAD 축척 표현 레코드로 읽고 씁니다.
  - 문자·치수 스타일과 블록 정의에 "주석" 선택을 넣었고, 주석 문자는 용지 높이로 묻습니다.
- 문자 도구: 한 줄 문자를 여러 줄 문자로 합치기(TXT2MTXT), 기준 문자에 맞춰 줄 세우기(TEXTALIGN), 속성 바로 편집(ATTIPEDIT).
- 원호 정렬 문자(ARCTEXT): 작업장에서 만들고 고치며, 호를 고치면 다시 놓입니다. DXF의 ARCALIGNEDTEXT를 읽습니다.

### 파라메트릭 구속
- 기하 구속 12종(GC*)과 치수 구속 7종(DC*), 자동 구속(AUTOCONSTRAIN), 매개변수 관리자(PARAMETERS), DELCONSTRAINT, CONSTRAINTBAR, DCDISPLAY.

- 리본에 파라메트릭 탭을 두었습니다.

### 블록과 참조
- 동적 블록 참조 편집(DYNPROPS·-DYNPROPS·RESETBLOCK·동적 그립): 가시성·뒤집기·선형·XY·회전·조회 매개변수와 이동·신축·축척·회전·뒤집기 동작.

- 참조 제자리 편집(REFEDIT·REFSET·REFCLOSE·XFADECTL): 작업 세트만 고치고 나머지는 흐리게 보이며, 외부 참조를 두 번 누르면 시작합니다.

- 블록 개수 창(COUNT)과 개수 표(COUNTTABLE), 블록으로·원래 좌표에 붙여넣기(PASTEBLOCK·PASTEORIG, Ctrl+Shift+V).
