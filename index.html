OpenCAD 무료 DWG·DXF 캐드

DWG·DXF 도면을 열거나 새로 만들어 그리고, 고치고, 저장하는 무료 2D 웹 캐드입니다. 설치나 회원가입 없이 브라우저에서 바로 사용하며, 도면 파일은 서버로 보내지 않고 이 컴퓨터에서 처리합니다.

최근 문서

이 브라우저에서 연 도면이 여기에 표시됩니다.

지원 형식과 기능

  • DWG R13~R2018, DXF R12~R2018(ASCII·이진) 열기, 새 도면 만들기
  • 선·폴리선·원·호 그리기, 이동·복사·자르기·모깎기 같은 수정, 그립 편집
  • 치수·지시선·문자·해치·표, 블록·도면층·배치 편집
  • DWG R2000~R2018, DXF R12~R2018 저장, 거리·각도·면적 측정
  • PDF·PNG·SVG로 출력

프로그램이 준비되면 ‘새 도면’으로 바로 그리기 시작하거나, 파일을 끌어다 놓거나 ‘파일 열기’를 누르세요. ‘예제 도면 열기’로 기능을 둘러볼 수도 있습니다. 최신 Chrome, Edge, Firefox, Safari 등 JavaScript와 WebGL2를 지원하는 브라우저가 필요합니다.

DWG·DXF 도면을 확인하고 수정하는 무료 캐드

전달받은 도면을 확인하고 고치거나, 새 도면을 그려 DWG·DXF로 저장해야 할 때 OpenCAD를 브라우저에서 바로 열어 사용할 수 있습니다. 명령 이름·단축키·마우스 동작은 데스크톱 2D 캐드와 같게 맞췄습니다. 예제 도면으로 기능을 먼저 둘러보세요.

DWG·DXF 파일 열기와 표시 문제 점검 · 거리·면적 측정과 PDF 출력 방법

어떤 캐드 파일을 열 수 있나요?

DWG R13~R2018과 DXF R12~R2018(ASCII·이진) 형식의 2D 도면을 지원합니다. 모형·배치, 도면층, 블록, 치수, 해치와 문자를 확인할 수 있습니다. 지원 범위 안에서도 일부 객체나 글꼴은 원본과 다르게 보일 수 있습니다.

무료로 도면을 편집하고 저장할 수 있나요?

도면 보기와 거리·각도·면적 측정뿐 아니라 새 도면 만들기, 그리기와 수정, 치수·블록·도면층 편집, DWG·DXF 저장도 무료입니다. PDF·PNG·SVG 출력도 지원합니다. 소스 코드는 MIT 라이선스로 공개합니다.

도면을 서버에 업로드해야 하나요?

선택한 도면 파일은 서버로 업로드하지 않습니다. 파일 읽기, 도면 표시와 저장은 사용 중인 브라우저에서 처리합니다. 설치 파일을 내려받거나 계정을 만들 필요가 없습니다.
