# 편집 기하 커널 메모

`src/edit/geom/`은 이동·회전·축척·대칭부터 간격띄우기·자르기·모깎기·분해·그립까지 도면 편집 명령의 기하 계산을 맡는다.
DOM을 쓰지 않는 순수 TypeScript이고, 공개 API는 `index.ts` 하나다. 동작 기준은 AutoCAD 2026이다(고른 점이 어느 쪽을
지우고 남길지 정하고, 결과가 없으면 AutoCAD식 한국어 안내를 돌려준다). 다른 CAD 프로그램 코드는 보지 않았고,
ezdxf(MIT)는 DXF 값의 뜻을 확인할 때만 참고했다.

## 결과 형식

모든 연산은 `EditResult`를 돌려준다.

| 필드 | 뜻 |
| --- | --- |
| `add` | 새 객체. 핸들은 `''`(호출한 쪽이 붙인다). 도면층·색·선종류·선가중치·선종류 축척·투명도·확장 데이터는 원본에서 잇는다 |
| `replace` | 핸들을 지킨 채 바뀐 객체(원본과 같은 종류). 확장 사전·반응자·하이퍼링크도 잇는다 |
| `remove` | 지울 핸들. 종류가 바뀌면(원 → 호, 원 → 타원, 구성선 → 광선 …) `remove` + `add` |
| `blocks` | 새 익명 블록(치수 `*D`, 표 `*T`). 핸들·레코드 핸들은 `''` — 문서에 넣을 때 붙인다. 이름은 문서마다 겹치지 않게 고른다 |
| `message` | 결과가 없거나 근사했을 때의 안내(`객체가 모서리와 교차하지 않습니다.` 등, `types.ts`의 `MSG`) |

새 객체(`add`, 새 블록 안 객체)에는 원본의 핸들·확장 사전·반응자·DWG 원본 본문(`dwgRaw`)을 남기지 않는다(`freshEntity`).
복사(COPY·ARRAY)는 `copyEntity`를 쓴다 — `transformEntity` 결과를 새 객체로 바꾼 것이다.

## 좌표

- 평면도(WCS XY)에서 계산한다. OCS 객체(원·호·폴리선·문자·블록 참조·해치·솔리드 등, extrusion (0, 0, −1)이 흔하다)는
  `ocs.ts`의 임의 축 알고리즘으로 WCS 조각을 만들고, 결과는 되도록 자연스러운(+Z) 객체로 쓴다.
  예: −Z 호를 자르면 WCS에서 같은 자리의 +Z 호가 된다. 분해(EXPLODE)는 원본 OCS를 지킨다(−Z 폴리선 → −Z 호).
- 2D 아핀 `[a, b, c, d, e, f]`: x' = a·x + c·y + e, y' = b·x + d·y + f(`src/text/layout.ts`와 같다). Z는 `opts.dz`만큼 옮긴다.
- 곡선은 조각(`curve.ts`: 선·호·타원호·NURBS)과 경로(`path.ts`)로 다룬다. 조각 매개변수 t ∈ [0, 1], 경로 매개변수 s = 조각 번호 + t.

## 규칙 요약

- 변환: 원·호는 닮음 변환이면 원·호, 아니면 ELLIPSE. 볼록도 폴리선은 비균등이면 유리 2차 SPLINE(정확). 문자는 대칭이고
  MIRRTEXT가 꺼져 있으면 상자를 거울상 자리에 두고 읽을 수 있게 둔다(TEXT·ATTRIB). MTEXT·치수 문자·다중 지시선 문자·공차는
  늘 읽을 수 있게. 해치는 대칭이고 MIRRHATCH가 꺼져 있으면 무늬 방향을 지키고 첫 꼭짓점이 옮겨 간 만큼만 무늬를 옮긴다.
  치수는 정의점·문자점을 옮기고 블록 내용을 같은 변환으로 옮긴 새 `*D` 블록을 돌려준다(축척하면 측정값과 블록의 숫자 문자도).
- 간격띄우기: 폴리선은 OFFSETGAPTYPE 0 — 세그먼트(선·호)를 늘여 만나게 하고, 만나지 않으면 꼭짓점 둘레 호로 잇는다.
  반지름이 0이 되는 호 세그먼트는 버린다. 원본에서 거리보다 가까워진 구간(자기 교차 고리, 열린 끝 둘레)은 잘라 낸다.
  폭은 원본 세그먼트의 값을 그대로 잇는다.
- 자르기: 고른 점을 둘러싼 가장 가까운 두 교점 사이를 지운다. 닫힌 곡선은 교점이 둘 이상이어야 한다(원 → 호, 닫힌 폴리선 →
  열린 폴리선). `quick`이면 교점이 없는 객체를 지운다(AutoCAD 빠른 모드). 자른 세그먼트의 폭은 테이퍼를 잇는다.
- 연장: 고른 점에 가까운 끝을 경계까지(선은 직선, 호는 원을 따라, 타원호는 타원을 따라, 스플라인은 끝 접선 방향 직선 부분).
  폭 테이퍼를 새 끝까지 잇고, 음수가 되면 0.
- 끊기: 두 점 사이를 지운다. 같은 점이면 그 점에서 둘로(닫힌 폴리선·스플라인은 그 점에서 열린다, 원·타원은 안내).
  원·완전한 타원은 첫 점에서 둘째 점까지 반시계를 지운다.
- 모깎기: 선끼리는 두 선(연장)의 교점에서 고른 점 쪽을 남기는 사분면, 호·원·타원·스플라인은 운반 곡선 교점(없으면 접점)을
  기준으로 고른 점 쪽을 남기는 모깎기 원 중 고른 점에 가장 가까운 것. 원·완전한 타원은 자르지 않는다. 반지름 0은 모서리,
  평행선은 반지름과 상관없이 첫 선 끝(고른 점 쪽)의 반원. 접점이 남길 쪽 끝을 넘으면 `반지름이 너무 큽니다.`
  같은 폴리선의 인접한 두 세그먼트는 볼록도 호를 넣고, 세그먼트 하나를 사이에 둔 두 직선은 사이 세그먼트를 바꾼다.
  `filletPolyline`은 직선-직선 꼭짓점마다(이전 모깎기 호는 새 반지름으로 바꾸고 반지름 0이면 모서리로), 짧은 세그먼트는
  건너뛰고 개수를 안내한다.
- 모따기: 선·광선·구성선·폴리선 직선 세그먼트. 거리 두 개 또는 길이 + 각도. 평행·호는 안내.
- 결합: 겹치거나 닿는 같은 직선·원·타원 위의 객체를 먼저 합치고, 끝과 끝이 닿는 객체를 잇고(스플라인·타원이 끼면 SPLINE,
  높이가 다르면 3D POLYLINE, 원본이 2D POLYLINE이면 그 종류, 그 밖은 LWPOLYLINE, 끝이 처음과 만나면 닫힘), 남은 낱개끼리는
  틈을 건너 합친다(같은 직선의 선, 원본 호부터 반시계로 같은 원의 호 — 한 바퀴면 원). 결과는 같은 종류의 원본(먼저 고른 것)
  핸들을 잇는다. 폭은 원본 폴리선이 폭 하나면 전체가 그 폭.
- 분해: 블록 참조는 한 단계(MINSERT 격자, 블록 기준점, OCS). 도면층 0·ByBlock 특성은 그대로, 속성은 현재 값의 TEXT
  (여러 줄 속성은 MTEXT), 상수가 아닌 ATTDEF는 버린다. 대칭·비균등 블록 안의 문자는 정확한 거울상·기울기로.
  폴리선 → LINE·ARC(폭은 버린다), 폴리페이스·메시 → 3DFACE(보이지 않는 모서리 비트), 치수·표 → 블록 그림, 지시선 →
  선(스플라인 지시선은 SPLINE) + 화살촉(블록 화살촉은 INSERT, 기본 화살촉은 SOLID), 무늬 해치 → LINE(솔리드·그라데이션은 안내).
- 신축: 걸침 다각형(두 점이면 사각형) 안의 정의점만 옮기고, 정의점이 모두 안이면 이동한다.
- 그립: `gripPoints`의 `id`로 `gripMove`. 호 끝 그립은 끝·중간점·다른 끝을 지나는 세 점 호, 중간 그립은 두 끝과 새 점
  (`arcMid: 'radius'`면 반지름만). 타원 축 그립은 그 축 반지름(단축이 길어지면 축을 맞바꾸고 매개변수 −π/2). 폴리선 세그먼트
  중간은 직선이면 평행 이동, 호면 새 점을 지나는 볼록도.
- 배열: `arrayRectangular`(열 +X, 행 +Y, angle만큼 회전), `arrayPolar`(360°면 간격 = 각도/개수, 아니면 /(개수 − 1),
  회전하지 않는 항목은 선택 범위 중심이 원을 따라 옮겨 간 만큼 이동). 원본은 두고 복사본만 `add`.

## 알려진 차이(AutoCAD 대비)·한계

- 타원·스플라인의 간격띄우기는 정확한 곡선이 아니라, 간격띄운 점(최대 240~960개)을 지나는 3차 SPLINE(조정점 정의, 닫힌 곡선은
  주기 형태)이다. 오차는 크기의 약 1e-5 이하. 맞춤점 정의로 쓰지 않는다.
- 치수의 신축·그립은 정의점·측정값만 정확하다. 블록 그림은 `stretch`·`gripMove`의 `regenDimension`(치수 생성기)을 넘기면 다시 만들고,
  없으면 근사한다(신축은 같은 영역으로 블록 내용을 늘이고, 문자 그립은 블록의 문자만 옮긴다). 각도·세로좌표 치수의 측정값은
  정의점에서 단순 계산한다.
- 모깎기·모따기 호·선은 첫 객체의 특성을 잇는다(AutoCAD는 두 객체의 도면층이 다르면 현재 도면층). 폴리선과 다른 객체의
  모깎기는 폴리선 끝 세그먼트를 자르고 호를 따로 만든다(폴리선에 합치지 않는다). 모깎기 호는 180° 이하만 고른다.
- 스플라인은 모깎기에서 늘이지 않는다(정의역 안의 접점만). 타원·스플라인 모깎기는 수치 해(뉴턴법)다.
- 모깎기·모따기 결과의 자리 고르기는 고른 점 기준의 규칙이라, 호·원이 여러 번 만나는 복잡한 경우 AutoCAD가 고르는 것과
  다를 수 있다.
- 뷰포트를 돌리면 경계 사각형을 감싸는 축 정렬 사각형으로 바뀌고 뷰 비틀기만 돈다(AutoCAD는 다각형 클립 뷰포트로 바꾼다).
- MTEXT의 비균등 축척·기울임은 높이·폭 비율로 근사한다(MTEXT는 기울일 수 없다). 블록 참조의 기울임도 가장 가까운
  축척·회전으로 바꾸고 안내한다.
- MTEXT 분해는 단선 글꼴 폭으로 줄을 나누므로 AutoCAD(트루타입 글꼴)와 줄바꿈 자리가 다를 수 있다. 서식(글꼴·색 바꿈)은 버린다.
- ACIS 객체(REGION·3DSOLID·곡면)는 ACIS 자료를 옮길 수 없어 변환하지 않고 안내한다(자료 없이 와이어만 있는 것은 옮긴다).
- ACAD_TABLE의 DXF 원본 태그는 방향(11·21·31)만 모델 값과 맞춘다. 축척·대칭한 표의 셀 크기는 원본 태그에 반영하지 않는다
  (그림 블록은 맞다).
- 결합의 허용 오차는 선택 범위 크기 × 1e-9(최소 1e-9)다. 그보다 큰 틈은 잇지 않는다(같은 직선·원의 틈 건너기 제외).
- 신축에서 호는 현의 높이, 폴리선 호 세그먼트는 볼록도(중심각)를 지킨다. 타원호는 중심만 본다(중심이 안이면 이동).
